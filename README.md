# Informed Diario — MVP1

This package is a responsive prototype for mobile and desktop.

## What is included
- Today view with world filters
- Date and region filters
- Executive impact ranking (demo data)
- Worlds and three pillars
- Source status drawer
- Source coverage panel
- Responsive desktop sidebar
- Mobile bottom navigation

## Run locally
Double-click `index.html` in Chrome or Edge.

## Publish free with Netlify
1. Create a free Netlify account.
2. Unzip this package.
3. In Netlify, use the manual/drag-and-drop deploy option.
4. Drag the folder containing `index.html`.
5. Netlify assigns a public HTTPS address like `your-project.netlify.app`.
6. Rename the site in Netlify if you want a cleaner free subdomain.

## Important
This MVP1 uses demo data only. Live RSS/API ingestion, authentication, AI summaries, saved items, and scheduled source refresh are planned for the next implementation step.
